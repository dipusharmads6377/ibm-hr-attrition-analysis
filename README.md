# IBM HR Analytics – Employee Attrition Analysis

Employee attrition analysis using Python, visualization and SQLite.

**Dataset:** 1,470 records and 35 project columns  
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, SQLite

## Questions
- Which departments have the highest attrition?
- Which roles are most affected?
- How does overtime relate to attrition?
- How do satisfaction and tenure relate to employee exits?

## Structure
`data/` dataset · `notebooks/` EDA · `sql/` queries · `visualizations/` charts

## Run
```bash
pip install -r requirements.txt
jupyter notebook notebooks/ibm_hr_attrition_analysis.ipynb
```

> The included dataset is a portfolio-ready modeled dataset created to match the scope described in the resume. It is not represented as the original Kaggle file.
